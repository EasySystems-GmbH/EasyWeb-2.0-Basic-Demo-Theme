# EasyWeb 2.0 Basic Demo Theme

Public **starter theme** for EasyWeb 2.0.

| Role | Path |
|------|------|
| Starter (edit here only) | [`theme/`](theme/) |
| Instance after copy | Core `Themes/site` (CMS) |

Do not treat this repo as a live CMS site theme. Docker first-boot and the Theme admin **Load starter theme** button copy into `site`; from then on, edit `site` (or your site workspace `theme/` via CLI).

See [`theme/README.md`](theme/README.md) for structure and CMS/CLI notes.
